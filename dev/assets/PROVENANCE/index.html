Provenance of the documentation assets

Every asset here comes from one of the showcase runs of 2026-10-23 listed in the Showcase Cases page (input_files/showcase/), produced on a laptop (Intel Core Ultra 7 155H, AVX build of the engine at the pin v2026.07.9, engine commit c67097a) by package commit 063a40a (its tree also carried the source-layout move of the following commit, which changed no code). Nothing was edited by hand: each figure is the package's own export, reduced in size with ImageMagick for the web (magick in.png -resize 1200x -strip out.png; the README montage to 1600 px, the animation halved and frame-optimised).
